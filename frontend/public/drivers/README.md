# Driver Images Directory

Place driver images in this directory with the following naming convention:

- `NOR.png` - for Lando Norris
- `VER.png` - for Max Verstappen
- `HAM.png` - for Lewis Hamilton
- etc.

The images should be named using the driver's 3-letter abbreviation in UPPERCASE.

Image format: PNG
Recommended size: 600x600px or larger
Background: Transparent or matching the design theme
